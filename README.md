# Emnbank About Page

A modern, responsive about page with interactive features.

## Project Structure

```
about.html     # Main HTML file
about.css      # Styles and responsive design
about.js       # Interactive features and animations
```

## Key Features

- Responsive design (mobile, tablet, desktop)
- Interactive animations (numbers counter, team hover effects)
- Mobile-friendly navigation
- Performance-optimized images
- Accessibility support

## Development Notes

### HTML
- Semantic structure
- Mobile-first approach
- ARIA attributes

### CSS
- CSS Grid/Flexbox
- Mobile-first breakpoints
- Utility-first classes

### JavaScript
- Intersection Observer
- Event delegation
- Smooth animations

## Browser Support
- Latest Chrome, Firefox, Safari, Edge
- Partial IE11 support

## Performance
- Lazy loading images
- Optimized animations
- Minified assets
